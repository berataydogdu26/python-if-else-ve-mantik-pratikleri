# 🐍 Python Karar Yapıları ve Mantıksal Operatör Pratikleri

Bu depo, Python öğrenim sürecimde karar mekanizmaları (`if-elif-else`), mantıksal operatörler ve harici modül kullanımı pratiklerini içeren 7 farklı algoritmayı kapsamaktadır.

## 📦 Proje İçerikleri

1. **Vücut Kitle İndeksi (VKİ) Hesaplayıcı (`04_vki_hesaplama.py`)**
   - Kullanıcının boy ve kilo verilerine göre VKİ değerini hesaplayıp sağlık kategorisini (zayıf, normal, kilolu, obez) belirler.


2. **Not Derecelendirme Sistemi (`06_not_sistemi.py`)**
   - Sınav ve sözlü notlarının ortalamasını alarak 0-5 arası harf/derece sistemine dönüştürür.


3. **Ehliyet Uygunluk Otomasyonu (`07_ehliyet_sorgulama.py`)**
   - Yaş ve eğitim mezuniyeti (lise/üniversite) şartlarını birlikte kontrol ederek ehliyet alabilme durumunu analiz eder.


4. **Araç Servis & Bakım Takip Sistemi (`05_arac_bakim_hesaplayici.py`)**
   - `datetime` modülü kullanılarak aracın trafiğe çıkış tarihinden bugüne kadar geçen zamanı hesaplar ve kaçıncı yıl bakımında olduğunu belirler.
